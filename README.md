# Legaseed CS AI

## 概要
Legaseedのカスタマーサクセス業務を支援するAIプロジェクトです。

## 最初に実装する機能
Infraパックの定期MTG準備を支援します。

- 顧客の理想・採用目標の確認
- 応募・選考・採用状況の分析
- 過去のMTG議事録・未完了事項の整理
- 課題と解約リスクの確認
- 定期MTGアジェンダ・質問・次のアクションの提案

## 利用予定のデータソース
- BigQuery
- Googleスプレッドシート
- Google Drive

## 開発方針
既存のLegaseed CS戦略アシスタントSkillを基に開発します。
機密情報・顧客データ・認証情報はこの公開リポジトリに保存せず、承認された接続先から取得します。
